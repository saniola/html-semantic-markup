# HTML Semantic Markup

An unstyled, semantic HTML markup of a design/development studio landing page.

## Features

- Semantic structure: `header`, `nav`, `address`, `main`, sections for hero, services, portfolio, and team

## Technology

- Semantic HTML (no CSS)

## Running

Open `index.html` directly in a browser, or serve the directory with any static file server, e.g.:

```
npx serve .
```
